# Smart NutriCalc — Калькулятор калорій та БЖУ

Десктопний/консольний додаток для розрахунку персональної добової норми калорій (за формулою Міффліна — Сан Жеора) та моніторингу балансу білків, жирів і вуглеводів (БЖУ).

## Функціональні можливості
- Розрахунок базового метаболізму (**BMR**) та добової витрати енергії (**TDEE**) з урахуванням рівня фізичної активності та мети (схуднення, підтримання ваги, набір маси).
- Пошук та фільтрація продуктів у локальній базі даних **SQLite** за назвою або категорією (із підтримкою кирилиці).
- Додавання власних продуктів до бази даних.
- Ведення щоденника харчування за прийомами їжі (Сніданок, Обід, Вечеря, Перекус) з автоматичним перерахунком залишку норми та візуалізацією прогресу.

## Структура проєкту
- `models.py` — моделі предметної області (`UserProfile`, `Product`, `FoodEntry`, `DailyLog`).
- `calculator.py` — математичне ядро (`NutritionCalculator`: формули BMR, TDEE, розподіл БЖУ).
- `repository.py` — шар роботи з локальною базою даних SQLite (`ProductRepository`).
- `main.py` — головний модуль користувацького інтерфейсу та управління сценаріями роботи.
- `test_nutricalc.py` — модульні тести (Unit Tests) для перевірки точності обчислень та пошуку.

## Запуск проєкту
Вимоги: **Python 3.10+** (використовується виключно стандартна бібліотека Python, додаткові залежності не потрібні).

```bash
python main.py
```

Для запуску модульних тестів:
```bash
python -m unittest test_nutricalc.py -v
```
